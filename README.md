## Selected Engineering Projects

### [Manufacturing AI Translation Platform](https://github.com/aoiminamoto/manufacturing-industrial-ai-tool-lab/tree/main/projects/jp-en-plant-translator)

A governed Japanese-English translation shikumi combining controlled terminology, manufacturing standards, resilient document workflows, HMI/image review, and engineering knowledge improvement.

Key contributions include bidirectional text and document workflows, PowerPoint processing, resumable background jobs, translation memory, and session-owned task isolation for concurrent pilot users.

A requirement-specific translation quality layer designed around plant-floor user needs, protected engineering identifiers, controlled terminology, format-preserving reconstruction, and deterministic validation.

### [Manufacturing & Industrial AI Tool Lab](https://github.com/aoiminamoto/manufacturing-industrial-ai-tool-lab)

A public-safe portfolio of industrial AI architecture, engineering prototypes, decision records, validation evidence, and manufacturing knowledge-system concepts built with synthetic or sanitized examples.
